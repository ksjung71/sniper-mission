# 스나이퍼 미션 — 테스트·배포·설치 가이드

> 순서: **① PC에서 테스트 → ② 사용자 OK → ③ GitHub Pages에 배포 → ④ 아이폰 홈 화면에 설치**
> 폰 배포(git push)는 PC에서 확인을 마친 뒤에만 합니다.

---

## 1. PC에서 테스트하기

### 1.1 실행
1. 프로젝트 폴더의 `play_pc.bat`을 더블클릭합니다. Python이 필요합니다.
2. 메뉴에서 번호를 고릅니다.

| 번호 | 내용 | 주소 |
|---|---|---|
| 1 | 일반 플레이 | `http://localhost:8123/docs/` |
| 2 | 테스트 모드: 모든 스테이지 열림, 화면 아래에 FPS·드로우콜 표시 | `http://localhost:8123/docs/?debug` |
| 3 | 같은 Wi-Fi의 아이폰에서 접속 | 서버 창에 뜨는 `http://192.168.x.x:8123/docs/` |

3. 끝낼 때는 작업 표시줄의 "Sniper Server" 창을 닫습니다.

### 1.2 PC 조작법
게임 화면을 한 번 클릭하면 마우스가 화면에 잠깁니다(포인터 락). 이 상태에서 마우스를 움직이면 조준됩니다. 브리핑의 "작전 시작"을 마우스로 누르면 바로 잠깁니다.

| 동작 | 키 / 마우스 | 대체 키 |
|---|---|---|
| 조준 | 마우스 이동 | 마우스 드래그(잠금이 안 될 때) |
| 발사 | 좌클릭 | Space |
| 스코프 켜기/끄기 | 우클릭 | E |
| 줌 확대 / 축소 | 휠 위 / 휠 아래 | Q(확대 순환) |
| 숨 참기 | Shift를 누르고 있기 | — |
| 재장전 | R | — |
| 야간투시(스테이지 4) | N | — |
| 일시정지 | Esc(마우스 잠금도 풀림) | 화면 왼쪽 위 II 버튼 |

- 같은 내용이 게임 안 **⚙ 설정 → PC 조작법**에도 있습니다.
- 조준 감도, 사운드, 화질, 상하 반전은 설정에서 바꿉니다. 값은 자동 저장됩니다.

### 1.3 아이폰 화면 흉내 내기 (Chrome)
1. 게임 화면에서 `F12`로 개발자 도구를 엽니다.
2. `Ctrl+Shift+M`(기기 툴바)을 누르고 위쪽 기기 목록에서 iPhone(예: iPhone 14 Pro)을 고릅니다.
3. 회전 아이콘으로 **가로**로 바꿉니다. 세로로 두면 "가로로 돌려주세요" 안내가 뜹니다(터치 기기 흉내일 때만).
4. 이 상태에서는 마우스 클릭이 터치로 처리됩니다. 화면 드래그 = 조준, FIRE·BREATH·SCOPE·ZOOM 버튼을 눌러 봅니다.

> 노치·홈 인디케이터 여백(safe area)과 실제 성능, 자이로, 무음 스위치는 PC에서 재현되지 않습니다. 이 부분은 실기기에서 확인합니다.

### 1.4 유용한 주소 옵션
| 옵션 | 효과 |
|---|---|
| `?debug` | 모든 스테이지 열림 + 성능 표시 + `window.__SNIPER__` 디버그 API |
| `?debug&stage=3` | 바로 스테이지 3 브리핑으로 |
| `?sw=1` | PC(localhost)에서도 서비스워커를 켜서 오프라인 동작을 시험 |

PC(localhost)에서는 평소 서비스워커를 끕니다. 파일을 고치면 새로고침만으로 바로 반영되게 하기 위해서입니다. 예전에 `?sw=1`로 남은 서비스워커와 캐시도 일반 접속 때 자동으로 지웁니다.

## 2. GitHub Pages에 배포하기

`docs/` 폴더가 배포물 전체입니다. GitHub Pages가 `main` 브랜치의 `/docs`를 그대로 서빙합니다. 빌드 과정은 없습니다.

### 2.1 처음 한 번
1. GitHub에서 새 저장소를 만듭니다(예: `sniper-mission`, Public).
2. 프로젝트를 올립니다. 둘 중 하나를 고릅니다.
   - **git 사용**
     ```bash
     cd C:/MyWork/Claude_PJT/Sniper_Game
     git init
     git add .
     git commit -m "스나이퍼 미션 첫 배포"
     git branch -M main
     git remote add origin https://github.com/<아이디>/sniper-mission.git
     git push -u origin main
     ```
   - **웹 업로드**: 저장소 페이지 → Add file → Upload files → `docs` 폴더를 통째로 끌어다 놓고 Commit
3. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**로 두고, Branch는 **main**, 폴더는 **/docs**를 고른 뒤 Save를 누릅니다.
4. 1~2분 뒤 `https://<아이디>.github.io/sniper-mission/` 주소가 생깁니다. PC 브라우저로 먼저 열어 확인합니다.

> 모든 경로가 상대경로라 `/<저장소이름>/` 같은 하위 경로에서도 그대로 동작합니다. `docs/.nojekyll`은 지우지 마세요.

### 2.2 업데이트 배포
1. `docs/js/config.js`의 `APP_VERSION`과 `docs/sw.js`의 `VERSION`을 **같은 값으로** 올립니다(예: `1.0.0` → `1.0.1`). 캐시 이름이 바뀌어야 폰이 새 파일을 받습니다.
2. PC에서 테스트한 뒤 commit·push합니다.
3. 폰에서 앱을 다시 열면 새 버전을 받습니다. 타이틀이나 스테이지 선택 화면이면 자동으로 새로고침되고, 게임 중이면 "새 버전이 준비됐습니다" 안내가 뜬 뒤 메뉴로 나갈 때 적용됩니다. 타이틀 왼쪽 아래의 버전 숫자로 확인할 수 있습니다.

## 3. 아이폰에 설치하기 (홈 화면 앱)

1. 아이폰 **Safari**로 `https://<아이디>.github.io/sniper-mission/`을 엽니다. 크롬 등 다른 앱으로는 홈 화면 앱이 만들어지지 않습니다.
2. 아래쪽 **공유** 버튼(□↑)을 누릅니다.
3. **홈 화면에 추가**를 누릅니다.
4. **"웹 앱으로 열기"**가 보이면 켜 둡니다(iOS 버전에 따라 없을 수 있음). 이름은 "스나이퍼"로 들어갑니다.
5. 홈 화면의 조준경 아이콘을 눌러 실행합니다. 주소창 없이 전체 화면으로 열립니다.
6. 한 번 실행해 두면 **오프라인(비행기 모드)에서도** 열립니다.

### 3.1 가로 화면과 세로 고정
- 게임은 가로 전용입니다. 세로로 들면 "가로로 돌려주세요" 안내가 뜨고 게임이 일시정지됩니다.
- 돌려도 화면이 안 돌아가면 **제어 센터 → 화면 방향 잠금(자물쇠 아이콘)**을 끕니다.

### 3.2 소리와 무음 모드
- 첫 화면을 탭하는 순간 소리가 켜집니다(아이폰 정책상 탭 전에는 소리를 낼 수 없음).
- Audio Session API를 지원하는 최신 iOS에서는 무음 스위치가 켜져 있어도 게임 소리가 나도록 설정했습니다(`navigator.audioSession.type = 'playback'`). 소리가 안 나면 **무음 스위치(또는 집중 모드의 무음)를 끄고** 볼륨을 올립니다.
- 소리를 끄고 싶으면 ⚙ 설정 → 사운드를 끕니다.

### 3.3 자이로 조준(선택)
- ⚙ 설정 → 자이로 조준을 켜면 권한 창이 뜹니다. **허용**을 누르면 폰을 기울여 조준할 수 있습니다(드래그와 함께 사용 가능).
- **HTTPS 주소(GitHub Pages)에서만** 동작합니다. PC 서버의 `http://192.168.x.x` 주소로 접속하면 켜지지 않습니다.
- 한 번 거절했다면 Safari 설정에서 해당 사이트의 "동작 및 방향" 권한을 다시 허용해야 합니다.

## 4. 문제 해결 FAQ

**Q. 화면이 검거나 하얗게만 나옵니다.**
- PC: `play_pc.bat`으로 서버를 켰는지, 주소가 `http://localhost:8123/docs/`인지 확인합니다. 파일을 더블클릭해 `file://`로 열면 동작하지 않습니다.
- `F12` → Console 탭에 빨간 오류가 있으면 그 내용을 전달해 주세요.

**Q. 고쳤는데 예전 화면이 계속 나옵니다.**
- PC: `Ctrl+F5`로 강력 새로고침합니다. 그래도 같으면 `F12` → Application → Service workers → Unregister를 누릅니다.
- 아이폰: 앱을 완전히 닫았다가(아래에서 위로 쓸어 올려 앱 전환기에서 닫기) 다시 엽니다. 배포할 때 버전 숫자를 올렸는지도 확인합니다(2.2).

**Q. 마우스가 잠기지 않습니다 / 클릭해도 발사가 안 됩니다.**
- 첫 클릭은 마우스를 잠그는 용도라 발사하지 않습니다. 잠긴 뒤부터 좌클릭이 발사입니다.
- Esc로 잠금을 푼 직후 약 1초 동안은 Chrome이 다시 잠그는 것을 막습니다. 잠시 뒤 화면을 한 번 더 클릭합니다.
- 그래도 안 잠기면 드래그로 조준하고 Space로 발사할 수 있습니다.

**Q. 아이폰에서 같은 Wi-Fi 주소(`play_pc.bat` 3번)로 접속이 안 됩니다.**
- Windows 방화벽 창이 떴다면 "개인 네트워크" 허용을 누릅니다.
- PC와 폰이 같은 Wi-Fi인지, 주소의 `192.168.x.x` 부분이 서버 창에 표시된 것과 같은지 확인합니다.

**Q. 별·최고 점수 기록이 사라졌습니다.**
- 기록은 브라우저 저장소에 남습니다. Safari 개인정보 보호(비공개) 모드에서는 저장되지 않습니다.
- 아이폰에서 **Safari로 연 게임과 홈 화면 앱은 저장소가 따로**입니다. 한쪽 기록이 다른 쪽에 보이지 않는 것은 정상입니다.
- 홈 화면 앱을 삭제하면 기록도 함께 지워집니다.

**Q. 게임이 끊깁니다.**
- ⚙ 설정 → 화질을 "낮음"으로 바꿉니다. "자동"은 프레임이 떨어지면 해상도를 스스로 낮춥니다.
- 저전력 모드에서는 iOS가 프레임을 30fps로 제한할 수 있습니다.

**Q. 게임 중 전화가 오거나 다른 앱으로 갔다 왔더니 멈춰 있습니다.**
- 백그라운드로 가면 자동으로 일시정지됩니다. "계속"을 누르면 이어집니다. 소리가 안 나면 화면을 한 번 탭합니다.
